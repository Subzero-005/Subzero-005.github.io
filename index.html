How I approach a tool

Every tool here starts from a real step in a designer's day, not from a technology looking for a use.

1 · Observe

Find the repetitive, error-prone step that steals time from actual design.

2 · Simplify

Pick the smallest tool that removes it. Use AI only where rules can't do the job.

3 · Ship

A one-click web UI that designers can use without touching code, plus tests so it keeps working.

4 · Document

A README that explains the problem, shows the result and gets someone started in two minutes.

CMF · Colour

CMF Palette Studio

Friction

Building a colourway starts with eyedropping dozens of reference photos by hand and retyping hex codes into a deck.

Tool
  • Drop in reference photos and get a merged, named colour board in seconds
  • Hex codes, palette share, CMF-style names and a finish hint for each swatch
  • Small accent colours are never dropped from the board
  • Exports PNG for Slack, PDF for print and JSON for reuse in other tools

AI · Search

Design Asset Search

Friction

Finding "that side-profile sketch with the orange accent" means scrolling folders named final_v3_REAL_final.

Tool
  • Search sketches, renders and references by describing them in plain English
  • Or upload an image to find visually similar work
  • Uses CLIP, a vision-language model, and runs fully offline so confidential work stays on the laptop
  • Incremental index, so refreshing only re-reads new or changed files

Real-Time GPU Image Filters

A live camera and video filter app with a Qt GUI. It uses custom CUDA kernels and CuPy, has presets like Cinematic and Artistic, shows an FPS and GPU overlay, and falls back to the CPU automatically.

MCHF-Net: Microplastic Detection

A multi-channel neural network that fuses holographic microscopy images using parallel EfficientNet backbones and dual attention. It flags uncertain detections for review and explains its decisions with Grad-CAM.
